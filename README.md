# Akdeniz HaySev Pati Haritası - Sosyal sürüm

Bu sürüm çalışan harita, mama noktaları, puanlar ve profil yapısını korur; alt menüde QR yerine Sosyal ekler.

## Kurulum
1. ZIP'i çıkartın ve içindeki dosyaları GitHub deposunun köküne yükleyin.
2. `supabase-social-migration.sql` içeriğini Supabase SQL Editor'da çalıştırın.
3. Vercel ortam değişkenleri `VITE_SUPABASE_URL` ve `VITE_SUPABASE_PUBLISHABLE_KEY` olarak kalmalıdır.
4. Framework: Vite, Build: `npm run build`, Output: `dist`.

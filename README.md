# Akdeniz HaySev Pati Haritası - Sosyal Sürüm

## Kurulum
1. Bu klasörün içindeki dosyaları GitHub deposunun köküne yükleyin.
2. Vercel ayarlarında framework Vite, build `npm run build`, output `dist` olmalı.
3. `supabase-social-migration.sql` dosyasını Supabase SQL Editor'da çalıştırın.
4. Vercel ortam değişkenleri: `VITE_SUPABASE_URL`, `VITE_SUPABASE_PUBLISHABLE_KEY`.

## Yeni özellik
Alt menüde QR yerine Sosyal bulunur. Sosyal akış fotoğraflı destek, seviye kutlaması, beğeni ve yorumları destekler.
